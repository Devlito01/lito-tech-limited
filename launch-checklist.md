# Lito Tech Limited Launch Checklist

This checklist is for the final stage before the website goes live.

## Content

- [ ] Review all page text for grammar, clarity, and consistency
- [ ] Confirm service descriptions are final
- [ ] Confirm About page story and company message are final
- [ ] Confirm contact details are correct
- [ ] Replace placeholder brand mark with final logo assets
- [ ] Confirm project/case study content is ready

## Design

- [ ] Review layout on desktop
- [ ] Review layout on tablet
- [ ] Review layout on mobile
- [ ] Confirm spacing and typography feel consistent
- [ ] Confirm buttons and links are visually consistent
- [ ] Confirm dark/light brand usage is correct

## Functionality

- [ ] Test all navigation links
- [ ] Test all internal page links
- [ ] Test `general-inquiry` form on the live Netlify site
- [ ] Test `project-inquiry` form on the live Netlify site
- [ ] Confirm submissions appear in Netlify Forms
- [ ] Test mobile menu behavior
- [ ] Confirm favicon is working

## SEO And Technical

- [ ] Add final page titles and meta descriptions
- [ ] Add favicon and final logo assets
- [ ] Add `robots.txt`
- [ ] Add `sitemap.xml`
- [ ] Optimize large images
- [ ] Check page loading speed
- [ ] Check browser compatibility

## Deployment

- [ ] Confirm hosting platform
- [ ] Confirm final deploy folder contents
- [ ] Upload final site files
- [ ] Test the live domain
- [ ] Test contact flow on the live website
- [ ] Confirm Netlify form notifications or dashboard workflow
- [ ] Share the site only after final live review
