# Netlify Checklist

Use this checklist before and after uploading a static site to Netlify.

## Before upload

- Confirm the homepage loads correctly
- Confirm all page links work
- Confirm styles and JavaScript files are present
- Confirm image folders are included
- Confirm `robots.txt` is included if needed
- Confirm `sitemap.xml` is included if needed
- Confirm the deploy folder does not include CMS or development files
- Confirm form markup is present if using Netlify Forms

## During upload

- Log in to Netlify
- Choose `Upload your project files`
- Select the clean deploy folder
- Wait for deployment to complete

## After upload

- Open the live site URL
- Check homepage layout
- Check mobile navigation
- Check services or important pages
- Check CMS-powered sections if the site uses an API
- Submit each live form once
- Confirm submissions appear in Netlify Forms
- Confirm the success or thank-you page works

## Final checks

- Rename the site if the temporary Netlify subdomain is not final
- Add a custom domain if needed
- Confirm SSL/HTTPS is active
- Share the site only after the live review is complete
