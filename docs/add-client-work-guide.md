# How To Add Client Work To The Website

This guide shows how to add finished client work to the Lito Tech Limited website.

## Where Client Work Goes

Finished client work should be added as a `Project` in Sanity CMS.

Projects can appear in:

- the homepage work section
- the Projects page
- the project detail page

## Step 1: Open Sanity Studio

Start the Studio if needed and open it in your browser.

Then go to:

- `Project`

## Step 2: Create a New Project

Click to create a new project entry.

## Step 3: Fill the Fields

Use these fields carefully.

### Title

This is the project name.

Example:

- `Website Redesign for a Local Business`
- `Web App Dashboard for Team Workflow`
- `SEO Content System for a Service Brand`

### Slug

This is the URL-friendly version of the title.

Example:

- `website-redesign-for-a-local-business`

Use:

- lowercase letters
- hyphens instead of spaces

### Tag

Use a short label for the project.

Examples:

- `Client Website Project`
- `Dashboard Concept`
- `Business Growth Project`

### Summary

This is the short project overview shown on the site.

Example:

`A premium website direction created to improve trust, clarity, and digital presence for a growing business.`

### Cover Image

Upload a good visual of the finished work.

Good options:

- homepage screenshot
- mobile preview
- dashboard screenshot
- project mockup

### Alt Text

Describe the image clearly.

Example:

`Homepage preview of a client website project by Lito Tech Limited`

### Industry

Write the business or project type.

Examples:

- `Professional Services`
- `Retail`
- `Internal Operations`
- `Education`

### Focus

Add the main focus points.

Examples:

- `Clarity`
- `Trust`
- `Usability`
- `Growth`
- `Structure`

### Body

This is the full project explanation.

A simple structure:

1. what the project was
2. what problem it solved
3. why it mattered

Example:

```text
This client project focused on creating a cleaner and more professional online presence for a growing business.

The goal was to improve clarity, strengthen trust, and present the business in a way that felt more modern and credible.

The final result is a website direction designed to support visibility, user confidence, and better presentation of the client’s services.
```

## Step 4: Publish the Project

After filling the fields:

1. click `Publish`
2. refresh the local or live site
3. confirm it appears in the Projects section

## Good Project Writing Tips

- keep the summary short
- keep the title clear
- use professional screenshots
- write the body in plain, confident language
- focus on results and value

## Important Client Work Reminder

Only post client work if you have permission to show it.

If needed:

- remove private information
- avoid showing sensitive details
- present it more generally as a case study

## Good Example Project

### Title

`Website Redesign for a Local Business`

### Tag

`Client Website Project`

### Summary

`A polished website direction created to improve trust, clarity, and digital presence for a growing service business.`

### Body

```text
This project focused on improving the online presence of a growing business through a cleaner and more modern website direction.

The goal was to make the business feel more credible, easier to understand, and better positioned for customer trust.

The final result is a digital experience designed to support stronger presentation, clearer messaging, and better business visibility.
```

## Quick Reminder

If you are adding finished work to your website:

- use `Project` in Sanity
- upload a good screenshot
- write a short summary
- add body text
- publish it
